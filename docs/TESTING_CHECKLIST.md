# Testing checklist (Stage 6)

Only real TVs can prove Hanivox works. Go through this list on your own devices and send me the results.
Use this format for each line: **works**, **does nothing**, or **wrong thing happened** (say what).

## Google TV (Onida / TCL)
- [ ] Find TVs lists the TV, or Add by address works
- [ ] Pair with the code, Connect
- [ ] Remote: arrows, OK, Back, Home, Menu
- [ ] Remote: volume up/down (try holding), Mute
- [ ] Remote: channel up/down (only if the TV has a tuner)
- [ ] Remote: play / pause / stop in YouTube
- [ ] App keys: YouTube, Netflix, Prime
- [ ] Inputs screen: for each of HDMI 1, HDMI 2, HDMI 3, HDMI 4, AV, TV and "input menu", press it and answer Yes/No
- [ ] Voice by typing: "open youtube", "go to hdmi 1", "switch to av", "go to tv channels", "close youtube"
- [ ] Power: Turn off, did the screen go off? What did the result say?
- [ ] Power: with the TV just in standby (screen off), Turn on
- [ ] Power: after adding the TV's MAC in My devices → Wake address, Turn on after a few minutes of standby

## Microphone
- [ ] Tap the mic on Home, say "increase volume"
- [ ] Say "switch to HDMI two" and "open Netflix"
- [ ] Does it say "Listening" clearly? Did it hear you?

## "Hey Vox"
- [ ] Switch it on, did the 40 MB model download?
- [ ] Say "Hey Vox" in a quiet room: did the app open Voice and start listening (buzz)?
- [ ] Say normal sentences for a minute: does it trigger by mistake? How often?
- [ ] Say "Hey Vox" from 2 metres away
- [ ] Leave it on for 15 minutes: how much battery did it use?

## LG TV (only if you can borrow one)
- [ ] Find TVs shows it. Connect. Accept the message on the TV
- [ ] Arrows, OK, Back, Home, volume, mute, "set volume to 20"
- [ ] Inputs screen lists the real inputs, switching works
- [ ] Open YouTube / close it
- [ ] Turn off, then Turn on (with Wake address saved)

## Samsung TV (only if you can borrow one)
- [ ] Find TVs shows it. Connect. Press Allow on the TV
- [ ] Arrows, OK, Back, Home, volume, mute
- [ ] Open YouTube / close it
- [ ] Turn off, then Turn on (with Wake address saved)

## Phone
- [ ] Install over the old app: are saved TVs still there?
- [ ] Close and reopen the app: does it remember the last TV?
